# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x (Prototype)   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within the VERTOTHON 2026 Operations Platform:

1. **Do not disclose publicly** in GitHub issues or discussions.
2. Contact the technical lead and organizers at security@vertofi.com or directly via private repository disclosure.
3. Include clear reproduction steps, affected endpoints, and potential impact.
4. The engineering team will acknowledge reports within 24 hours and issue patches swiftly.

## Security Principles
* Role-based access control (RBAC) enforced across all endpoints.
* Row Level Security (RLS) enabled on all database entities.
* Payment integration locked behind feature flags until authorized.
